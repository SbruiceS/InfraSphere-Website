Configuration Drift

Configuration drift is the difference between the intended desired state of infrastructure and the actual observed configuration.

Examples

  • Missing resources that should exist
  • Unexpected resources that were not declared
  • Mismatched settings (network rules, storage classes, security groups)

Why It Matters

Drift increases operational risk, complicates troubleshooting, and can violate policy. Detecting it early allows controlled alignment rather than uncontrolled change.
