Security Model

Designed with explicit trust boundaries, least privilege, and defense in depth. Phase 1 limitations are documented; production readiness is not claimed.

Opaque Sessions

Portal stores only a session UUID in an HttpOnly, SameSite=Strict cookie. Access tokens never leave the server.

CSRF & Rate Limits

HMAC CSRF tokens on state-changing requests. Login and API rate limiting. Strict security headers (CSP, X-Frame-Options, etc.).

RBAC & Audit

Deny-by-default authorization. All security-relevant actions recorded. No hardcoded secrets; environment or secret manager only.

Threat Model

STRIDE analysis documented. Input validation, optimistic concurrency, and provider isolation. Report vulnerabilities privately.
