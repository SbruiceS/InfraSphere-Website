# InfraSphere Website

Official professional website for **InfraSphere** — the independent, self-hosted, open-source multi-cloud infrastructure control plane by **Cosinfotechs Solutions**.

## Features of this site

- Modern, responsive, dark-themed design matching the InfraSphere brand
- Security-conscious: Content-Security-Policy, no third-party scripts, strict headers meta
- Accessible navigation and focus styles
- Showcases architecture, security model, providers, and getting started
- Links to the main [InfraSphere](https://github.com/SbruiceS/InfraSphere) repository

## Local preview

Open `index.html` in a browser, or serve with any static server:

```bash
python3 -m http.server 8080
```

## GitHub Pages

This repository is set up for GitHub Pages. Enable it in Settings → Pages → Deploy from branch `main` / root.
